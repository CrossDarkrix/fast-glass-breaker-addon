# Fast Glass Breaker

Break glass instantly with any vanilla pickaxe.

This addon allows all vanilla pickaxes to instantly break glass blocks and glass panes with virtually no mining delay. It works with regular glass, all stained glass colors, and all stained glass panes.

<img src="https://raw.githubusercontent.com/CrossDarkrix/fast-glass-breaker-addon/main/screenshots/fast-glass.gif" width="95%" height="95%" alt="fast-glass.gif">

## Features

### Works with all vanilla pickaxes

*   Wooden Pickaxe
*   Stone Pickaxe
*   Iron Pickaxe
*   Golden Pickaxe
*   Diamond Pickaxe
*   Netherite Pickaxe

### Instantly breaks

*   Glass
*   Glass Panes
*   All 16 Stained Glass colors
*   All 16 Stained Glass Pane colors

### Silk Touch Support

*   Glass drops itself when using a Silk Touch pickaxe
*   No item drops without Silk Touch (same as vanilla behavior)

### Additional Features

*   Plays the vanilla glass breaking sound
*   Multiplayer compatible
*   Lightweight Script API implementation
*   No custom tools required

## How It Works

When a player swings a pickaxe at a glass block or pane, the addon immediately removes the targeted block, making glass nearly instant to mine while preserving normal Silk Touch functionality.

## Notes

*   Only glass-related blocks are affected.
*   Other blocks retain their normal mining speed.
*   Reinforced Glass is not affected.
*   The addon uses vanilla pickaxes and does not add new tools.

## Why Use This Addon?

Breaking large windows, domes, greenhouses, and glass structures can be slow and repetitive.

Fast Glass Breaker makes glass removal quick and convenient while keeping vanilla gameplay balance through proper Silk Touch support.
